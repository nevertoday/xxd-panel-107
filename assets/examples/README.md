# XXD Panel 107 samples

This directory contains the reviewed extension samples displayed by all five localized project READMEs.

## Original release slots

- `sample-01`–`sample-04` remain reserved for verifiable original release works and their source post.
- Generated extensions are identified separately and are never presented as original release samples.

- Each work was generated independently and directly from its own original reference through Panel 107's canonical prompt, uses intelligent English copy, and passes the strict 50:50 two-region direction review.
- Every image word occupies a real grammatical position in one readable text-to-image sequence; the replaced word is not printed again, and sticker walls, card grids, nested photo strips, third bands, and second-pass results are rejected.
- No artwork from another numbered Panel, broken placeholder, or banner is accepted as a sample.
