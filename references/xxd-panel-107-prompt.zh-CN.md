# XXD Panel 107｜运行适配器（中文）

本文件不是第二套美学提示词。生成时必须先完整读取 `references/original-prompt/zh-CN.md`；它是 107 的唯一创作与审美权威。当前归档没有 Markdown 标题，因此原始提示词全文逐字进入生图请求；若未来归档增加纯管理用途的标题，只省略该标题。本文件只负责把用户本次选择的运行变量追加到正文末尾。

## 不可改写的边界

- 不总结、翻译、扩写或“优化”原始提示词。
- 不额外规划颜色、色板、材料、构图、留白、标题、微文案或美学动机。
- 原始提示词中的颜色处理逻辑保持原样：它要求从照片取色就取色，它规定固定色系就使用固定色系。
- 原始提示词中的文字逻辑由图像模型执行；外层 Skill 不提前写标题或文案包。
- `TOP_BOTTOM` 在用户未指定其他最终尺寸时使用原文 3:4，并始终保持上下严格 50:50；`LEFT_RIGHT` 映射为左右严格 50:50。只有纯设计与壁纸模式替换双区容器，不覆盖图像替词逻辑。
- 下半或右半必须是可按语法顺序读懂的真正图像替词句。图像词占据被删文字的位置，被替换词不得再印成文字；禁止完整句旁配图、贴纸墙、卡片列表或规则宫格。
- 每张成品只追加一个已选模式的指令，不把其他模式作为备选项一同发送。

## 公共交付前言

```text
【本次模式交付覆盖｜当前成品】

本段是当前展示模式、现实来源可见性、最终画布与设备交付的最终依据。
TOP_BOTTOM 在未明确选择其他最终尺寸时使用原文 3:4，并始终上下等分；LEFT_RIGHT 将同一等分原则映射为左右等分；
DESIGN_ONLY 与 WALLPAPER_PACK 才替换旧双区容器。
原始提示词关于设计转译、主体身份、颜色、材料、质感、内部构图、留白、
文字气质与排版的规则继续保持有效。

REALITY VIEW 指原始提示词定义的真实照片或事实场景。
TRANSFORMED DESIGN 指原始提示词定义的设计转译结果。

最终画布：<比例和／或准确 WIDTHxHEIGHT>
构图方式：一次生成一张连贯的完整画布
精确分区：TOP_BOTTOM 与 LEFT_RIGHT 必须启用 50:50

颜色完全服从原始提示词已有的颜色处理逻辑。
除非用户明确提出颜色修改，否则不要增加、替换、概括或重新规划任何色盘。
```

## 四选一模式块

每张成品只追加下面一个模式块。

```text
输出模式：TOP_BOTTOM
创建一张完整画布（用户未明确选择其他最终尺寸时使用原生 3:4），严格分成两个等高横向区域：REALITY VIEW 只占上方 50%，TRANSFORMED DESIGN 只占下方 50%，分界位于垂直中点。不得出现第三带、底栏、跨区标题条、边框或过渡区；所有图像替词句内容均留在下方 50%。
```

```text
输出模式：LEFT_RIGHT
严格分成两个等宽竖向区域：REALITY VIEW 只占左侧 50%，TRANSFORMED DESIGN 只占右侧 50%，分界位于水平中点，两个区域都从画布顶边延伸到底边。不得出现第三带、底栏、跨区标题条、边框或过渡区；所有图像替词句内容均留在右侧 50%。
```

```text
输出模式：DESIGN_ONLY
整张画面完全使用 TRANSFORMED DESIGN 的设计转译语言。REALITY VIEW 只作为不可见的主体身份、结构关系、颜色逻辑与事实依据；每个可见元素都属于原始提示词规定的设计转译结果，而不是未经转译的原始照片展示。
```

```text
输出模式：WALLPAPER_PACK
设备：<本张已确定的 PHONE、IPAD、DESKTOP 或 WATCH>
壁纸关系：<已确定的 INDEPENDENT 或 LINKED>
为当前设备创作一张完整画布的 TRANSFORMED DESIGN 壁纸。REALITY VIEW 只作不可见参考；根据设备画布与可用屏幕空间重新构图，每个可见元素都属于设计成品。
```

在所选模式块后只追加一种文字模式。若用户还有其他明确要求，将其逐字放在文字模式块之后，也就是全部内容最末尾。

### 模型根据原始提示词生成文字

```text
TEXT MODE: ORIGINAL_PROMPT_GENERATED
TEXT LANGUAGE: <用户确认的语言或地区>

由图像模型按照原始提示词已有的文字生成逻辑生成。所有可见文字都应从
当前图片的内容、气质或隐喻中自然生长。任何以事实或资料形式呈现的信息，
必须来自用户提供、图片清晰可见或已经核实的真实信息；没有事实依据时，
使用诗意而非事实性的表达。运行层本身不是画面文案的来源。

先形成一句完整底层句子，再删除适合视觉化的词，并把来自原图、统一手绘重构的
图像词放回这些词原本的语法位置。可见成品必须沿阅读顺序形成
“文字→图像词→文字→图像词→文字”；被替换的词不得再次以文字出现。
```

### 使用用户准确文字

```text
TEXT MODE: USER_EXACT
TEXT LANGUAGE: <用户确认的语言或地区>
TEXT: 「<用户准确文字>」

以用户原句作为完整底层句子，不改写、不翻译、不纠错、不添加其他文案。
从中选择适合视觉化的词时，只把这些词从可见文字中删除并以图像词原位替代；
其余可见文字逐字保持。排版方式与字体气质继续服从原始提示词。
```

### 不要文字

```text
TEXT MODE: NONE
画面中不得出现任何字母、文字、数字、标题、标签、Logo 或伪文字。
这会主动放弃 107 的图像替词句身份，仅在用户明确接受该例外时使用。
```
